# Navzeroth 0.9.2 — in-game addon window and desktop redesign

Developer prerelease for Windows. Version 0.9.2 follows the published 0.9.1 local-data
research preview. It adds an in-game addon window, a redesigned desktop interface and
much stronger end-to-end and native Windows regression checks. It is not complete
playable content and not a 1.0.0 candidate.

## Changes since published 0.9.1

- **In-game addon window.** `/anav` opens one window that exposes the addon features
  through buttons and fields, with a tooltip on every control. A minimap button and an
  Options > AddOns page open the same window. The window adds no event, timer, reload,
  clipboard access or socket bridge; observations stay inside the permitted addon
  environment and desktop state remains imported snapshots. Three window keys were
  added to the saved settings without changing `db_version`; a 0.9.1 addon drops them
  when it next merges the table. See [the addon window guide](../compatibility/ADDON_GUI.md).
- **Build 70425 development admission, UNVERIFIED.** The addon adapters admit
  `1.60.1.70425` / interface 16001 for development capture only, because the owner's
  installation metadata reports it. No addon run on that build is recorded. The release
  target stays Forever 1.60.1 / 70374 / interface 16001 and every live acceptance row
  stays bound to 70374. See [build capabilities](../compatibility/BUILD_CAPABILITIES.md).
- **WoW-inspired desktop redesign.** A new design system (tokens, shared primitives,
  contextual help tips, themed `#reference` page) and a two-group application shell.
  Every screen moved onto it. It bundles unmodified Inter (4.1) and Cinzel with their
  SIL OFL notices; see `apps/desktop/THIRD_PARTY.md`. Default, high-contrast and
  forced-colours modes have tested contrast pairs, including a composite bound over
  the backdrop. The interface is original and not affiliated with Blizzard Entertainment.
- **Original-art backdrop.** An inline SVG backdrop drawn for this project; no game
  art is used.
- **Settings refresh fix.** The 60-second refresh no longer unmounts the Settings form
  and discards unsaved edits; a dirty draft is kept against the revision it was made
  from, so saving over a changed store still fails the revision check.
- **End-to-end harness.** A Rust harness runs the full addon on builds 70374 and 70338
  through capture, export, desktop import, plan binding and refusal cases, and checks
  that the desktop command map equals the registered Tauri handlers.
- **Native Windows smoke and upgrade checks.** The hosted package job drives the
  installed app through real WebView2 and Tauri IPC and upgrades from the published
  0.9.1 setup. These are hosted-runner regression checks only.

## Downloads

Download `AzerothNavigator-0.9.2-x64-setup.exe`, `AzerothNavigator-addon-0.9.2.zip`,
`CANDIDATE_NOTES.md`, `SOURCE_COMMIT.txt` and `SHA256SUMS.txt`. Verify the checksum
entries before installation. Follow the repository Windows and addon installation
guides; close WoW and keep private backups before updating the addon. The installer
is unsigned.

## Limits and remaining work

Unverified for this release:

- WebView2 visuals of the redesign (checked in Chromium, not by eye on Windows).
- Screen-reader behaviour of the help tips and live announcements.
- The addon window, minimap button, taint and keyboard focus on a live client.
- The unsigned installer under Windows SmartScreen.
- Anything on build 70425 beyond its recorded installation metadata.

Stable readiness is unchanged: stable and candidate readiness remain false, with the
blockers `release-readiness` reports (66, the same count as at 0.9.1; see the
[0.9.2 release handoff](../handoffs/2026-10-17-v0.9.2-release.md)). Preview
publication is permitted and is distinct from stable readiness. No playable content
pack, private client data or catalogs are included. Local-data output remains
research-only. Complete licensed content, independent inventories, objective and
advancement bindings and frozen-candidate live and interactive Windows acceptance
remain required for 1.0.0.
