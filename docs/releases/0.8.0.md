# Azeroth Navigator 0.8.0 — route and display controls preview

Developer prerelease for Windows. Desktop character data remains imported snapshot
state; game observations remain inside the permitted informational Lua addon.

## Changes

- Route inspection provides keyboard hop selection, complete tail pagination and
  one exact map/floor/instance frame at a time. Fit selected or same-frame route
  endpoints without inventing roads, positions or floor connections. Changed original
  planning provenance invalidates selection and late replies; gaps stay explicit.
- Explicit addon HUD size/font/contrast/reset commands use bounded local preferences
  and a conservative recorded-build, method and actual boolean combat gate. Deferred
  application refreshes the plan evaluation. Movement is saved only from a successful
  permitted point observation; session-only movement survives routine refreshes.
- The ordinary reference window has an opt-in focused-main Ctrl+Shift+F8 shortcut
  and explicit requested interactive/pass-through control. Receipts distinguish
  dispatch from actual queried visibility/topmost; no unsupported interaction-mode
  observation is invented. The reference webview remains read-only.
- Main headings wrap at narrow widths and increased text size, preserving content
  and semantics rather than clipping or reducing the user's chosen font size.

## Evidence limits and next iteration

Synthetic frame/clock/gate checks and command-mocked browser flows establish bounded
engineering behavior, not interactive Windows, screen-reader or gameplay acceptance.
Actual recorded70338 UI restrictions, taint, focus/action-bar interference, movement,
font/contrast readability and reload/display behavior remain unverified. Native
window focus/hit testing, DPI, multiple displays, installation and ordinary hardware
performance remain unverified; exclusive fullscreen is outside the reference-window
experiment. No game input hook or gameplay automation is introduced.

Schemas, storage10 and dataset identities are unchanged. Historical Forever
reference70205/16001, revision forever-atlas-r1 and its0.1 producer remain historical;
they are not relabeled as70338. Real catalogs, role models, source permissions,
recorded-client field/event/plan/session checks, actual party message capabilities,
complete sessions and official Forever API support remain missing or unverified.
World expansion stays evidence-gated and remote hosting remains deferred. Reaudit
the actual published source before claiming no further ready engineering remains.

The next parallel iteration addresses two audited engineering gaps: local content
pack comparison must accept the typed explicit empty map_embeddings array, and the
existing Forever source declarations need a typed sources.json sidecar. These tasks
preserve schema1 and recorded source policies; unknown redistribution rights remain
blocked. This preview does not claim that all ready implementation work is exhausted.
