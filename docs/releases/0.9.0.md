# Navzeroth 0.9.0 — independent sources and guided-observation preview

Developer prerelease for Windows. This is an interim release, not full 1.0.0
content or acceptance. Desktop state remains imported snapshots; live game
observations remain inside the permitted informational addon.

## Changes since 0.8.1

- Reference-content/content-pack v2 contracts, typed model/dungeon/acquisition/
  eligibility consumers, larger bounded catalogs, indexing/caching/pagination,
  compatible storage migration and rollback infrastructure.
- Deterministic nine-domain inventory investigation, source admission and retained
  offline source builds, with Linux/Windows parity and provenance-preserving
  reliability/trusted-freshness ranking. Four admitted narrow scopes produce 1,685
  reference facts; none is yet verified target-usable 70374 gameplay content.
- Typed party coverage, candidate/publication separation, offline material
  manifests and a guided Windows acceptance kit. Stable gates remain mandatory.
- Experimental exact-build 70374 support, selectable export text, bounded private
  capture inspection, guarded separate quest-completion reads and explicit
  `/anavsession start-quests <profile>` recording. Ordinary manual mode remains;
  turn-in time is unclassified, rewards are ignored and reload returns to idle.
- Source-identified pre-version-bump development checks confirmed readable quest
  completion flags and one actual turn-in/export/import flow on build 70374.
  These results do not establish full or version-0.9.0 acceptance.

## Assets and installation

Download `AzerothNavigator-0.9.0-x64-setup.exe`,
`AzerothNavigator-addon-0.9.0.zip`, `CANDIDATE_NOTES.md`, `SOURCE_COMMIT.txt` and
`SHA256SUMS.txt`. Verify all four checksum entries and exact source metadata.
Follow the repository's Windows/addon installation guides. Close WoW before
updating the addon, retain private backups and use distinct anonymous profiles.

No playable full-content pack or permission-incomplete historical atlas pack is
included. The source-knowledge catalog remains a separate research artifact and
cannot authorize content activation or stable publication.

## Remaining 1.0.0 work

are missing across all nine domains. Fresh objective mapping/advancement/deviation
bindings and full frozen-candidate live/interactive Windows acceptance, including
full-corpus performance, remain required. Do not treat preview allowance or hosted
smoke tests as stable readiness.
