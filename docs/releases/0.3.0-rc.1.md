# Azeroth Navigator 0.3.0-rc.1 candidate

This is a downloadable CI candidate for review and focused testing. No GitHub
release or tag is created; published v0.2.0 and earlier releases stay unchanged.
Downloads expire under CI artifact retention. SOURCE_COMMIT.txt identifies the
built source; SHA256SUMS.txt verifies download integrity.

Changes: guarded manual quest/equipment capture and position-read diagnostics;
explicit runtime plan paste/import and conservative HUD; acquisition-aware gear
comparisons with editable assumptions and Gear screen; bounded immutable session
imports, migration v5, explicit recorder and Sessions analytics/history; Planner
route inspection including final stopping travel and exact-dataset geometry gaps.

Gear scores are versioned model scores, not damage/survival estimates. Synthetic
examples are labelled; no real game tables or playable quest content are invented.
Practical results compare one acquisition-backed upgrade against a complete
baseline; probabilistic values remain conditional estimates.

Sessions remain opt-in and explicitly sampled. Default spans are unclassified;
gaps, uncertain clocks and observed progression remain separate. Reload cannot
resume an old monotonic timeline. Imported Lua is parsed only as bounded literals.

Routes show schematic endpoint links where exact projection exists. Missing
imagery/transforms and incompatible maps/floors keep the ordered route and gaps.
The imported addon plan is runtime-only and reload clears it; missing completion
mapping cannot advance steps. Snapshot/dataset changes invalidate desktop results.

Windows installer is unsigned unless the CI signing secret is configured. Hosted
smoke installation and command-mock Chromium tests are separate from live-client
and native-window acceptance. Experimental70338 bindings require the consolidated
[live checklist](../compatibility/RC1_LIVE_CHECKLIST.md); full live acceptance remains
unverified. Real content, stage progression, joint planning, party messaging and
calibration remain later work requiring missing inputs/evidence.
