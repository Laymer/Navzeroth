# 1.0.0 declared scope — preparation

This is scope documentation, not publication or a passing readiness report.
The versioned [deferred feature list](../../release/v1/deferred-features.json)
is displayed in Content and recorded as inventory boundaries.

Trainer-spell gameplay, talents, professions and enhancements are deferred.
Reference/browsing data does not promise learning/purchase recommendations,
talent allocation, profession/recipe/crafting plans or item-enhancement advice.
These exclusions never satisfy a missing required record in the supported scope.

Stable release notes must retain these exclusions, historical source editions and
builds (including admitted Forever70245), inferred travel and authored estimates,
unsigned status and actual measured resource use/hardware limits. No ordinary-PC
performance claim or live Forever verification is inferred. Content, models and
dungeon guidance still require genuine enumerated coverage and signed receipts.
