# Azeroth Navigator v0.1.0

First public **developer-preview prerelease** for Windows x64. This release provides
an offline desktop companion and a diagnostic addon with synthetic examples.
**Live World of Warcraft Forever compatibility is not verified.** It is not yet a
complete gameplay planner or a verified real-content guide.

## Downloads and installation

- **AzerothNavigator-0.1.0-x64-setup.exe**: per-user Windows desktop installer,
  bundled addon and addon installation/removal helper.
- **AzerothNavigator-addon-0.1.0.zip**: readable Lua addon source and BSD-3-Clause
  license for manual installation.
- **SHA256SUMS.txt**: checksums for both downloads. On Windows, compare
  `Get-FileHash .\AzerothNavigator-0.1.0-x64-setup.exe -Algorithm SHA256` with the
  matching entry. Checksums establish file integrity, not publisher identity.

The installer is unsigned; Windows may show a SmartScreen warning. Install only
from this repository's release assets. WebView2 may require a one-time download
if missing. After installation the companion works offline without API credentials.
The addon helper asks for your game's AddOns folder; silent install/uninstall leaves
existing game addons untouched. The game must be closed before modifying addon files.

[Installation, removal and build instructions](https://github.com/Laymer/Navzeroth/blob/v0.1.0/docs/compatibility/WINDOWS_INSTALL.md).

## Included

- Today and Imports screens with bounded snapshot imports, profile selection,
  capture-age reporting, history and explicit audited snapshot promotion.
- SQLite storage with migrations through v4; content revision staging, activation,
  rollback and coverage inspection.
- Demo Atlas, local Party configuration and per-character declared-quest eligibility.
- Single-character Planner with explicit start/stop, budget, manual utilities and
  time estimates, exclusions, uncertainty and rejection explanations.
- Bounded manual `ANAV1:` plan export with explicit Copy, snapshot/revision checks,
  deterministic identities and freshness limits. Lua transport validation retains
  the prior plan when replacement fails.
- Diagnostic addon and pure Lua foundations for predicates, plan validation, HUD
  and synthetic gear evaluation. Source remains readable and freely available.

## Verification and compatibility

The application targets Windows x64. Hosted Windows 2025 evidence covers building
with the pinned Rust 1.99.0 / Node 24.15.0 toolchain, silent installation, first
launch for 20 seconds with SQLite creation, and silent uninstall retaining user
data and an existing synthetic addon. The addon helper passes 30 checks on both
Windows PowerShell 5.1 and PowerShell 7.

The inherited application baseline passed eight CI jobs: Rust format, Rust Linux,
Rust Windows, Lua static checks, frontend Linux/Windows, mocked Chromium workflows
and native Windows shell compilation/tests. Release preparation goes through fresh
CI; the tag workflow rebuilds, smoke-tests and checksums the actual release assets.
Final run links and artifact verification are appended to the GitHub release after
completion. Earlier evidence: [main CI](https://github.com/Laymer/Navzeroth/actions/runs/38375740810),
[Windows packaging](https://github.com/Laymer/Navzeroth/actions/runs/38374945174).
Browser command mocks and hosted smoke tests do not establish interactive native
or live-game behavior.

## Known limitations

- Forever client build, TOC interface `16001`, addon loading, SavedVariables layout
  and real snapshot round trips remain unverified. Fixture/addon export-key
  differences are documented; no end-to-end live workflow is claimed.
- Shipped desktop imagery/examples are synthetic. No playable real quest segment,
  acquisition catalog, all-class gear model or verified geographic route coverage
  is claimed. External LFS atlas imagery is not bundled.
- Automatic addon step advancement, live addon import UI, joint-party planning,
  session recording/calibration and desktop gear/session screens remain future work.
- Interactive installer dialogs, bare-machine prerequisite setup, code signing,
  native UI interaction and live-client performance have not been verified.
- Linux/macOS installers are not supplied. The source tree retains the documented
  Linux GTK-stack `glib` advisory GHSA-wrw7-89jp-8q8g; it is not a Windows dependency.
- Unknown, stale, unsupported and restricted observations remain explicit. No game
  memory access, injection, packet decoding or input automation is included.

Back up local application data before experimenting with prerelease builds.
Uninstall keeps user data unless explicitly selected for deletion; addon
SavedVariables removal is a separate explicit helper option.
