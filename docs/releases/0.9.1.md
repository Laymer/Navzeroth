# Navzeroth 0.9.1 — private local-data research preview

Developer prerelease for Windows. Version 0.9.1 includes the prepared 0.9.0
foundations and the subsequently merged private local-data workflow. Version
0.9.0 was not published; this release supersedes that interrupted publication.

## Changes since published 0.8.1

- Content v2 contracts, typed model/dungeon/acquisition/eligibility consumers,
  bounded catalogs, indexing, pagination and compatible storage foundations.
- Retained offline source builds with provenance and cross-platform parity.
  The admitted scopes provide 1,685 reference facts, with zero verified
  target-usable gameplay facts; all nine 70374 inventories remain unknown.
- Experimental 70374 addon support, copyable exports, guarded quest-completion
  reads and manual quest-turn-in session recording. Desktop state remains
  imported snapshots; observations remain inside the permitted addon.
- Private local installation inspection, read-only local CASC extraction,
  isolated resource-limited workers, bounded WDC research decoding and immutable
  private catalogs. CLI verification/coverage and desktop inventory controls
  preserve missing, unsupported, invalid and unknown dispositions.
- Pinned native/parser sources, metadata and third-party notices are retained.
  Private game files, extracted tables and catalogs are not release assets.

## Limits and remaining work

This is a developer preview, not complete playable content or 1.0.0 acceptance.
Local-data output is research-only and does not activate gameplay content.
The measured development extraction used 70425/enUS; it is not 70374 content
or acceptance. Cache/hotfix/media support, gameplay projections, durable jobs,
settings and full private-inventory release integration remain unfinished.
See `docs/data/LOCAL_EXTRACTION.md` for supported commands and explicit gaps.

The full target remains Forever 1.60.1 / 70374 / interface 16001. Complete licensed
content, independent inventories, objective/advancement bindings and frozen-candidate
live/interactive Windows acceptance remain required. Hosted packaging smoke tests
and synthetic tests do not establish operator acceptance. No playable content pack
or private client data is included. Existing stable-release gates are unchanged.
