# Azeroth Navigator 1.0.0-rc.1 — development prerelease

This is an **unsigned development prerelease**, not a stable release or an
acceptance candidate. The `rc.1` name does not establish playable-content
completeness, live-client acceptance or ordinary-Windows acceptance. Candidate
and stable readiness remain false. Stable 1.0.0 publication is outside this release.

## Included capabilities

The Windows desktop imports bounded addon snapshots and sessions, preserves their
exact edition/build identity, and exposes the Planner, Atlas, Gear, Party,
Dungeons, Sessions and recovery workflows. Demonstrations and automated tests use
labelled synthetic fixtures; they are not evidence that those workflows have
complete verified game content.

Local research now has durable preparation, cancellation and unchanged-source
resume; explicit locale/resource choices; optional selected-installation metadata
change detection; bounded cache/addon/guide input staging; revision-bound local
media previews; provenance-aware gameplay fact and tooltip research; and explicit
research-reference selection, comparison and rollback. Imported Lua is inert data.
Unknown, unsupported, restricted, stale, false and zero remain distinct.
Research references never authorize playable advice. There is no live desktop
bridge, game memory access, packet decoding or input automation.

The addon offers manual capture/export, plan import/HUD controls and manual
session recording inside the permitted addon environment. Desktop state is an
imported snapshot, not live game state. Admission of an API or build is not proof
that a field is readable in every context.

This continuation also repairs concurrent private lifecycle-index initialization and migration, atomically
reserves test directories, bounds native startup readiness, preserves sanitized
IPC error codes, and verifies SemVer upgrade ordering. The strict 90% executable
line gate applies to each Rust and TS/TSX file, including native aggregation and
missing-file detection.

## Install, upgrade and remove

The release contains exactly these five files:

- `AzerothNavigator-1.0.0-rc.1-x64-setup.exe`
- `AzerothNavigator-addon-1.0.0-rc.1.zip`
- `CANDIDATE_NOTES.md`
- `SOURCE_COMMIT.txt`
- `SHA256SUMS.txt`

No playable content pack, private client files, exports, caches, catalogs, guides
or extracted images are included. Dependency notices and retained dependency
sources are bundled with the application; an empty release-material selection
produces no material ZIP or material manifests.

Download only from the project's verified release page. In PowerShell, compare
`Get-FileHash .\AzerothNavigator-1.0.0-rc.1-x64-setup.exe -Algorithm SHA256` and
`Get-FileHash .\AzerothNavigator-addon-1.0.0-rc.1.zip -Algorithm SHA256` with their
exact entries in `SHA256SUMS.txt`. The manifest covers the four payload files;
matching hashes verify integrity, not publisher identity.

The installer and application are unsigned: no Authenticode publisher identity
is claimed. SmartScreen may warn. Stable-release signing requirements remain in
force. The per-user installer targets `%LOCALAPPDATA%\Azeroth Navigator`; missing
WebView2 may require Microsoft's runtime bootstrapper and network access.

Before upgrading from 0.9.2, use **Backup and recovery → Create consistent backup**
and retain the private backup outside the installation and application-data folders.
Then close the application. Install the RC over it and inspect the imported data and
research selections. Older writers refuse newer private-index schemas; do not
bypass downgrade refusal or overwrite a database to force an old executable to run.

Close WoW before addon changes. Back up the existing addon and SavedVariables,
then extract the ZIP's `AzerothNavigator` folder into the actual client's
`Interface\AddOns` directory. The optional addon helper requires explicit folder
selection and retains ownership/running-game checks. Never send personal exports
to the repository.

Remove the desktop through Windows Installed apps. Retained application data and
backups are separate from the executable; delete them only if you intend to lose
that state. Remove only the owned addon folder with WoW closed; SavedVariables
removal is a separate, explicit choice. See the [Windows](../compatibility/WINDOWS_INSTALL.md) and
[addon](../compatibility/ADDON_INSTALL.md) guides for detailed paths and preservation behaviour.
