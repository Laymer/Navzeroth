  mist), default, high-contrast and forced-colours modes, declared contrast pairs. The
  site accent `#9184d9` is lightened to `#a396e4` because it measured 4.10:1 on the raised
  surface. `--text`, `--muted`, `--surface`, `--background` now resolve to real tokens.
- `theme/contrast.test.ts`: parses `tokens.css` and asserts every declared pair (WCAG

  in `apps/desktop/THIRD_PARTY.md`. Both were fetched from those URLs and their sha256

  CI evidence, and nothing in the repository re-fetches upstream. What the repository can
  reproduce is the committed files against the recorded hashes (`theme/fonts.test.ts`,
  added in G6). No system-font fallback was needed (the stacks still fall back if a face
  fails to load). (Wording corrected in V3.1, G4 review #10.) Cinzel ships as TTF
  because upstream publishes no WOFF2 and converting would make it a modified version.
- `.gitattributes` keeps the fonts and THIRD_PARTY.md byte-exact on every platform.
- `tauri.windows.conf.json` ships the two OFL notices and THIRD_PARTY.md under

- `src/ui/`: `Button` (primary/secondary/ghost/danger), `Panel`, `Field` (render-prop,

## Decisions
- App is dark-only (`color-scheme: dark`); the three token modes are default, high
  contrast and forced colours.
- Global element styling uses zero-specificity `:where()` selectors so existing screen
  CSS keeps winning until G5 moves screens onto the primitives.
- Nav group titles are `<p>` (not headings) so the heading outline is unchanged.
- The body has no background: html paints the canvas so the z-index -1 backdrop shows.

  `libdbus-1-dev`/pkg-config, which this machine lacks. The Rust change is one builder
  call and was only rustfmt-checked; hosted CI is the evidence.
- Unverified: WebView2 visuals (Chromium is the proxy), whether `backgroundColor`
  actually avoids the white flash natively, native font rendering/hinting, and the NSIS
  resource layout (`font-notices/`), which only the Windows packaging job exercises.

  over the backdrop is judged from the screenshots only.
- Screens still use raw controls styled by the global rules; HelpTips are not yet used
  on any screen (G5).
