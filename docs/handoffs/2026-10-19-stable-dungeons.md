## Source basis and implementation

The admitted public CMaNGOS z2815 SQL dump contains exterior ghost-entry map/X/Y
in `instance_template`; no elevation is supplied. Generator v2 retains optional
planar estimates, derivation and uncertainty as additive world-data schema-1
fields. It preserves exact source portal points separately. Converter v3 prefers
a directly placeable portal, then a planar estimate. Blackwing Lair's source
portal is inside another instance; its exterior ghost point supplies the visible
estimate. No elevation was fabricated as zero.

Nodes and dungeon records cite the inferred rule plus historical source evidence.
Existing preparation checklist labels carry the derivation and uncertainty to
the desktop's imported-member checks. Generic roles, repairs, supplies and bag
space guidance is explicitly authored heuristic advice with unknown conditions;
it never passes readiness or invents current inventory. Source level suggestions
are not mandatory entry requirements. Actual entry access stays unknown.

Missing area associations use map ID plus normalized root-area name only when
unique. Missing/ambiguous matches remain unresolved. The actual corpus resolves
all supported area associations and preparation quest lists. Deadmines links
source quests 166, 167, 168, 214 and 2040, retaining normal quest eligibility and
prerequisite checks. The association promises source zone-linked quests, not all
possible quest relationships or target-build correctness.

Map169 (Emerald Dream) retains an explicit raw unused/test exclusion reason:
maxPlayers, levels and ghost map/X/Y are all zero. It stays in the raw 27 records,
is excluded from the 26 supported catalog records, and appears in the generated
summary's exclusion list. Zero defaults are not interpreted as a real entrance.
