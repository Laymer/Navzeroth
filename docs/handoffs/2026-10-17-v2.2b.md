# V2.2b: build 70450 development admission for local data

Owner and sole writer: Claude Code subagent (Opus 5.5); claim [2026-10-17-v2.2b](../claims/2026-10-17-v2.2b.md).
Baseline main `920b1e8`. Branch `feat/V2.2b-build-70450`.

## Why

The owner's `wow_classic_beta` installation updated from 70425 to
`1.60.1.70450` (installation metadata read by the coordinator on 2026-10-17,
build key `84bea4233331e390fda8724c6f91ffa5`). Extraction and DBD selection only
admitted 70374 and 70425, and the vendored WoWDBDefs did not list 70450.

## Limitations

- Re-vendoring changes `METADATA_SHA256`, and catalog verification requires the
  current value, so existing private catalogs (the 70425 research catalogs) no
  longer verify with this build and must be re-extracted. The extractor profile
  hash also changes because `src/*.rs` changed. Expected identity behaviour.
- 70450 is development input only, like 70425: never the release target, never
  relabelled; `target_build_unconfirmed` remains a standing projection gap.
