## Implemented
- apps/desktop: React 19, Vite 8, strict TypeScript (6.0.3, because
  typescript-eslint does not yet support TS 7), ESLint, Vitest + Testing Library.
  Scripts: dev, build, typecheck, lint, test:unit, tauri. test:e2e is not implemented.
- Typed command boundary (src/commands): CommandMap for get_app_status,
  list_profiles, get_character_snapshot; a CommandAdapter seam with a demo
  adapter (serves the synthetic contract fixture) and a Tauri adapter; the
  Result-returning client normalizes anything thrown into a safe AppError.
- The DEMO label comes from the reported data_mode, so stored data cannot be
  mislabelled and demo data cannot lose its label. Observation states
  (unknown/unsupported/restricted/not applicable) render as distinct text.
- crates/app (azeroth-app): framework-free handlers over the validated
  fixture, tested on Linux. Unknown profile gives a safe INVALID_INPUT.
- apps/desktop/src-tauri (azeroth-desktop): explicit per-command registration,
  empty capability set (no shell/fs/opener), restrictive CSP, bundling off,
  placeholder icons.
- CI: Linux/other Rust jobs exclude azeroth-desktop; new job "Desktop shell
  Windows" runs typecheck, lint, unit tests, build, then clippy and test on the
  native crate. It is not yet a required check on main.

- No window was launched; the Tauri adapter, capabilities and CSP are not
