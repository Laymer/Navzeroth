matches the rule context, every confidence is verified_on_build, all evidence
and declared source-conflict references are clear, and each registered source's
known verified_revision matches the active dataset revision. Separate reasons
preserve missing evidence, unverified evidence, conflicts and unknown/mismatched
source revision. Fixture rules are explicitly synthetic and exempt only for
engineering demonstration. No real game records are authored or relabelled.

snapshot contracts. The category input panel says precisely what is needed;
prerequisite/upgrade explanations refer to authored dependencies/model inputs
without claiming any missing quest/spell/item. The optional bag-space checklist
is disabled initially, stores explicit user declaration, and never measures slots
or resets without user action. Additive defaulted fields keep existing reminder
state document v1 readable. No new exchange schema or migration is needed.
