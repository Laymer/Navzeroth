## Changed

- `crates/core/src/release_party.rs`: party support matrix **schema 2**. `target`
  is a required member that must equal `release::expected_target(2)`, so it is
  `null` while the release target is pending. Sizes 1 to 40. Workflow
  applicability is fixed in code (`applies`, `workflows_for`): size 1 has
  `joint_planning` (the single-character planner), `stale_members`,
  `advancement`, `review`; the other four are not applicable to one person.
  Schema 1 (70374, sizes 2 to 40, all eight workflows) is unchanged.
- `crates/ingest/src/pack/v2.rs`: compares the matrix target with the catalog
  only when it is non-null. `crates/cli/src/release.rs`: the release gate now also
  requires the matrix target to equal the inventory's frozen target (a pending
  target was already refused earlier by `release_target`).
- `crates/core/src/content_v2/authored.rs` (new): `validate_authored`, which
  refuses game facts in authored content (rules in
  [AUTHORED_CONTENT.md](../data/AUTHORED_CONTENT.md#authored-content-rules)).
- `content/authored/slice-v1/` (new): the authored pack input. `catalog.json`
  (revision `navzeroth-authored-slice-r1`), `sources.json`, `party-support.json`,
  12 procedures, 2 evidence documents. All canonical.
- `.gitattributes`: `content/authored/**/*.md` kept LF, since the matrix pins
  those bytes by SHA-256.
- `scripts/validate-content-v2-schema.mjs`: also validates the authored catalog.
- Tests: `crates/core/tests/release_party.rs` (schema 2 case),
  `crates/core/tests/content_v2_authored.rs` (record set, authored rules, ten
  refused invented-fact edits that still decode as v2),
  `crates/cli/tests/authored_slice.rs` (build + verify of the committed input,
  canonical bytes, catalog hash, solo/duo rows; edited procedure or catalog
  refuses to build).
- `docs/data/AUTHORED_CONTENT.md` (new).

## Assumptions

- Role weights are authored levelling heuristics
  ([role-model-assumptions.md](../../content/authored/slice-v1/evidence/role-model-assumptions.md)),
  weight source `documented_model` citing `navzeroth-authored-v1`. No WoWSims
  code or numbers were used; its admitted scope is a Classic paladin pointer for
  reference only, so it is not cited.
- Models apply by declared role (`role_is`); the predicate language has no class
  field, so callers must match `class` themselves.
- Catalog context `wow_forever 1.60.1.70425 / 16001`, locale enUS: a development
  label required by the format, not a build claim. Rebuild for the live target.
- `sources.json` declares the project's own writing as BSD-3-Clause and
  redistributable, so the pack reports `distribution_eligible: true`. That is not
  a release admission: the source still needs an admission-registry entry and a
  pinned `verified_revision` (currently unknown) before the gate accepts it.
