# V1.4: slice acceptance matrix

Owner and sole writer: Claude Code (Opus 5.5); claim [2026-10-17-v1.4](../claims/2026-10-17-v1.4.md).
Baseline main `4decacc`. Branch `feat/V1.4-slice-matrix`.

## Changed

- `crates/core/src/release.rs`: schema 2 evidence `matrix` of `MatrixRow`s (class,
  `level_min`/`level_max`, zone, party size, status, method, operator, time,
  environment, artifacts). `level_bands(slice)` splits the level range at ten-level
  boundaries (1-10, 11-20). `assess_matrix` requires every class in every band and
  every zone and party size in at least one row; any row outside the slice, a
  duplicate ID, or a failed, automated or partial row blocks; pristine
  `unverified` live rows are pending observations (candidate mode may defer them).
  `classes: null` blocks once ("cannot be checked until the slice classes are
  known"). Schema 1 evidence can't carry a matrix. Matrix artifacts join the
  verified evidence files.
- Docs: the release contract README and a runbook paragraph describe the matrix.
