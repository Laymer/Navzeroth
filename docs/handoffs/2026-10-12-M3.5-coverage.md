## Goal and scope
Wave-1 package P9 of [ADR 0003](../decisions/0003-wave1-parallel-delegation.md)
(recorded on branch docs/wave1-coordination, not yet on main). A pure core
library, `crates/core/src/coverage.rs`, that turns one reference dataset into a
deterministic coverage and content validation report (plan 17 M3.5, 8.4 steps
5-7, 8.5). It is the only owner of prerequisite-cycle and dangling-predicate
reference validation. It counts the six `Confidence` categories and recorded
`EvidenceRecord.conflicts`, and defines no precedence or conflict model (P8).
No CLI wiring, no `docs/data/COVERAGE.md`, no schema or TypeScript export.

## Implemented
- `content_report_from_json(&str) -> ContentReport`: runs
  `decode_envelope::<ReferenceDataset>`. A decode failure (an invalid
  coordinate, an unresolved structural reference, an oversized or unsupported
  document) gives `passes: false` and `outcome: decode_failed {code, message}`,
  built from the `ErrorCode` and the static `AppError` message only.
- `content_report(&Envelope<ReferenceDataset>) -> ContentReport`:
  - Header: revision, namespace, fixture flag, edition, build, interface,
    `coverage_class` (demo / reference_fixture / reference) and
    `forever_reference_content` (true only for a non-fixture reference-namespace
    `wow_forever` dataset; it says nothing about verification).
  - Per-collection coverage for all 11 collections: total; records with and
    without evidence; evidence links by confidence (all six categories, zeros
    kept); per-field `known / unknown / unsupported / restricted /
    not_applicable` counts for every `Observation` field. Edge counts by
    `EdgeStatus`; evidence records with conflicts and conflict links; licence
    and `observed_at` statuses of evidence records. No percentages.
  - Errors (fail the report): `quest_prerequisite_cycle`,
    `dangling_predicate_quest`, `dangling_predicate_objective`,
    `dangling_predicate_item`, `undeclared_predicate_area_map`.
  - Gaps (listed, never fail): `possible_quest_prerequisite_cycle`,
    `record_without_evidence`, `unverified_evidence`, `unknown_map_transform`,
    `uncalibrated_image`, `unprojectable_position` (tallied by
    `ProjectionGap` variant through `atlas::project_position`).
  - Findings are a closed `#[serde(tag = "code")]` enum carrying IDs and
    DataContext-qualified keys (`RecordRef`, `ItemKey`, `MapKey`), never imported
    free text. Errors and gaps are `BTreeSet`s, so both lists are sorted and
    deduplicated. The report holds no timestamp and no `HashMap`.
  - Predicate walker and Tarjan SCC search are iterative (explicit stacks) and
    private to the module; `ReferenceDataset`'s private helpers are untouched.
- Tests: `crates/core/tests/coverage.rs` (16 tests), fixtures under
  `fixtures/coverage/v1` (16 synthetic datasets plus `manifest.json`), including a
  test that every fixture is listed with a declared outcome.
- Library edit outside the new module: one line, `pub mod coverage;`, in
  `crates/core/src/lib.rs`.

## Decisions
No ADR (ADR 0003 forbids numbered ADRs from packages). Package-local choices
that P2 or M3.6 may revisit:
- A predicate quest reference to a quest not in the dataset is an error
  (M3 acceptance). Cross-dataset references are not modelled.
- Objective references resolve against quest stages and `Objective.id`
  together, since `ObjectiveId` names both.
- Prerequisite edges come from `prerequisites` only and only for positive
  requirements: `quest_state` with `value: true`, or `equals` on a quest field
  with `true`, after cancelling `not` pairs. `value: false` or an odd number of
  `not` creates no edge. `participant_state` is walked transparently.
- Conditional edges: a branch of `any` (or of `all` under an odd number of
  `not`, by De Morgan) is conditional. A cycle of unconditional edges is an
  error. A cycle that needs a conditional edge is reported as
  `possible_quest_prerequisite_cycle` (a gap, `passes` stays true) unless it
  contains an unconditional cycle. Cycles are SCCs of size > 1 or self-loops,
  with sorted quest IDs and sorted lists.
- "Unverified evidence" means the record has evidence and none of it is
  `verified_on_build` or `publisher_documented`. This is a membership test, not a
  precedence. Records with an empty evidence list are listed separately.
- The `map_images` evidence-link count uses `MapImage.evidence` only (not
  calibration, pin or applicable-build evidence). `nodes` carry no evidence list
  and report no evidence counts.
- Positions checked for atlas gaps: travel node positions and known quest
  locations. Decoded coordinates are always in [0,1], so an invalid coordinate
  is only visible as a decode failure.
- The report DTO is `Serialize` only; no `JsonSchema`, no `schemas/v1` or
  `exchange.ts` entry. Adding it to the contract is wave-2 work.
- Fixtures use build/interface `SYNTHETIC`, namespace demo, `fixture: true`.
  The verified bucket is tested with an in-memory non-fixture reference-namespace
  variant built inside the test, and by reading
  `content/forever/datasets/forever-atlas-r1.json` read-only.

## Limitations
- Cross-dataset references are errors by default; M3.6 or P2 may add an
  allow-list.
- Only prerequisite quest cycles are analysed. Travel-graph cycles are
  legitimate, and embedding cycles are already rejected at decode.
- Predicate sites other than quest `prerequisites` are checked for
  dangling references but contribute no cycle edges.
- Item and acquisition coverage is structural; nothing checks real game data.
- Coverage does not check image layer files or digests (CLI `prepare-atlas`).
- The `any`/`not` conditional analysis is syntactic; it does not decide
  satisfiability.
