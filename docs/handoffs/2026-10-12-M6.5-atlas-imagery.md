## Goal and scope
Make the owner-supplied Eastern Kingdoms travel atlas the base of the future
interactive map with a snapshot-location marker, without the desktop shell
(M1.4) existing yet. This PR delivers the parts that do not need the UI:
rights/source records, additive imagery contracts, pure projection, the
`prepare-atlas` CLI, Git LFS intake, the demo atlas, the reference content
dataset and CI checks. The Atlas screen (PR-B) and the M10 overlay window
(PR-C) follow M1.4; see the plan sections T7-T11 recorded in ADR 0002.

## Decisions
- Flight masters are image-space pins; `nodes`/`edges` stay empty.
- `map_embeddings` is a separate collection; embeddings require exact context
  equality; the position build is carried unchanged through the chain.
- `no_embedding` from the plan was folded into `no_image_for_map` and
  `build_mismatch { image: null }`; `in_instance` was added.
- LFS covers `content/forever/**/*.png` only; demo PNGs stay plain blobs so CI
  can decode them. `*.png binary` prevents EOL normalization.
- The source file was renamed to lowercase to satisfy `AssetPath`.
- `image` 0.25.10 (png only) and `sha2` 0.10.9 are pinned in the CLI; new
  transitive crates include png 0.18.1, fdeflate 0.3.7, flate2 1.1.10,
  miniz_oxide 0.8.9/0.9.1, crc32fast 1.5.2, zlib-rs 0.6.8, typenum 1.20.1.
- git-lfs 3.8.0 (released 2026-08-28) was installed user-locally at
  `~/.local/bin/git-lfs` after verifying the release checksum, and enabled
  with `git lfs install --local` (repository config only). The owner still
  needs Git LFS on Windows Git before pulling there.

## Limitations and remaining risks
- Calibration is a provisional full-frame assumption (`inferred`); the in-game
  continent map bounds, aspect and axis orientation are unverified, so
  projected markers are approximate and must be labelled so by the UI.
- Build `1.60.1.70205`, interface `16001` and map id `1415` are placeholders
  from the poster footer, community exports and the Classic-era convention;
  M0.4 evidence may require a new dataset revision.
- Third-party licences (WoWForeverMap.com, EndgameTools.com, Blizzard
  artwork) are not recorded; redistribution rests on the owner's statement for
  the composite only.
- The GitHub LFS quota figure was not verified this session; LFS pushes of
  about 38 MB are expected for this branch.
- Windows: LFS smudge, `prepare-atlas` and the bash pointer step on the
  Windows runner are unverified until hosted CI runs.
- No desktop, overlay or live-client behaviour exists yet; nothing is
  labelled live.
