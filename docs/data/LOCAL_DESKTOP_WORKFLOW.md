# Private desktop content workflow

The desktop interface and Windows installer remain English. Installed content
locales are independent selections. Only the reviewed `wow_classic_beta` product
and exact admitted development builds are supported; no edition/build fallback
or acceptance readiness follows from importing client data.

On first launch, choose addon snapshots, local research/compatibility, or Today.
The choice is saved before navigation and opens that workflow on later launches.
Settings → Starting workflow can change the next-launch choice. These actions do
not import, extract or activate anything. The existing installer separately offers
optional addon installation/update/removal, defaulting to No, with a manually
selected AddOns directory. The addon helper retains its running-game and ownership
checks. Uninstall keeps unrelated addons and SavedVariables intact.

Compatibility and coverage → Local Data selects an installation through a native
picker. Restore saved installations/jobs explicitly. Select one or more declared
content locales; new extractions use request protocol 3. `small`, `balanced`,
`large` and `max` remain resource ceilings, not parallelism claims. Save content
choices to retain locales and the resource preset. Preparation, progress,
cancellation, recovery and unchanged-source resume remain durable. Protocols 1/2
retain their historical encoding/readers; unknown request versions refuse.

Build detection is optional and initially off. While the application is open it
polls only the selected `.build.info` every 500 ms and requires 750 ms stable
bytes, size and modification time. Unix also binds file identity; Windows
file-ID replacement detection remains unverified. It retries failed staging at
most three times for one stable identity. A changed source produces an immutable
private metadata candidate, with no archive/cache scan, extraction or activation.
Review detected changes; acknowledge the staged candidate to advance the baseline.
If the file changes again, acknowledgment refuses. Saved opt-in resumes on opening
the workflow. Turning it off cancels and wakes its worker. A metadata change does
not establish a new supported build, readable archive or available game fact.

For a completed catalog, select cache/addon exports by kind in the native picker
and enter the exact input locale. Stage each explicitly. Cache staging requires
the native current closed-game guard and exclusive-against-writing read handles;
WSL cannot substitute a process claim for that guard. Snapshot/session Lua is
parsed as inert bounded data. Unsupported cache formats remain unsupported;
unknown counts are not zero. Cache metadata pages contain at most 200 envelopes,
with raw payloads kept private. Saved material paths stay in the private index,
with at most 32 selections; Forget frees a path selection without deleting any
retained imported revision. The same selection list supports private guides and
original authored packs.

Media discovery lists reviewed table references, at most 200 per page. Select up
to 128 unique file IDs; extraction runs in the isolated bounded worker against
the original catalog/source fingerprints. All unsupported/read-refusal states
remain visible. Verified PNG previews use revision-bound opaque IDs under the
existing local atlas scheme; the serving adapter accepts exact GET paths without
queries and sends no-store/nosniff. No general file URL, file path or uncalibrated
coordinate is accepted as a navigation location.

Research references explicitly bind selected input/media revisions, optionally
building research guide facts from those inputs. Dependency lists are candidates,
not integrity or completeness evidence; preparation reproduces all selected
artifacts and exact build/locale closure, applying the chosen resource ceiling
also when dependencies are empty. Selecting an incompatible, stale or altered
artifact refuses. Review and select a research reference explicitly; replacement
requires its displayed generation and a compatible diff. Rollback requires actual
prior activation history and a reviewed diff. Retained references can be listed
in pages of at most 200; selecting one revalidates it against the current catalog.
Development match indicators never enable advice or acceptance.

For a verified reference, build exact inventory across all nine domains, optionally
joining a selected verified original authored pack. Exact IDs/source kinds and
imported counts remain separate from independently required counts and reviewed
completeness. Missing independent counts stay unknown. A private guide can be
reviewed against bound research guide facts for the declared Human research class
and solo/duo mode. Findings remain research findings; observed turn-ins cannot
prove universal eligibility or prerequisites, and duo eligibility remains
unverified. Findings pages are at most 200 and bound to the complete replay hash;
continuation requires that digest and refuses changed source/facts. Tooltips use
the bounded inert evaluator; unsupported expressions, missing scalars and cycles
remain explicit. No imported markup or Lua executes.

Private index schema 3 adds CAS workflow preferences, opaque selected paths and
latest changed-build pointers transactionally, preserving historical catalogs,
checkpoints and both activation histories. Failed work cannot replace active
usable state. Old writers refuse the newer schema. No private source, cache,
export, guide or extracted image belongs in a public release or Pages asset.
