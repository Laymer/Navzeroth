CODE SIGNING

Integrity and identity.
Separate checks.

The development installer and application are unsigned. No Authenticode publisher identity is claimed. Stable-release signing requirements remain in force.

Verify the bytes

Download from the project's release page. Compare SHA-256 hashes with SHA256SUMS.txt and retain SOURCE_COMMIT.txt with the version-specific notes.

The manifest covers the payload files, not itself. Matching hashes tell you the download agrees with the published manifest.
