Plan at the war table. Ride out with the map.

Navzeroth is a desktop companion and in-game addon for World of Warcraft: Forever. The addon takes a reading of your character when you call for it. The desktop spreads that reading across an atlas, weighs routes, gear and fellowships, and hands you a plan to carry back into the game.

The navigator's oaths

Only when called

The addon acts when you type its command. It runs no background process and never reads chat.

No hand on your keys

No input automation, no socket bridge into the client and no hidden telemetry.

You choose the path

The installer never guesses where your game lives. You point it at the AddOns folder yourself.

Unknown stays unknown

Missing, stale, restricted and unsupported facts are named as such and never filled in by guesswork.

Instruments of the table

Six instruments for the road ahead.

Each instrument reads only the snapshots you imported and the content you activated. Where an input is missing, the screen names the gap instead of filling it.

The journey of a plan

From the field to the table, and back again.

A plan travels by your hand at every step. Nothing crosses between the game and the desktop unless you carry it.

  1. I

    Take a reading

    In game, call the addon by name. Where the client allows it, it records your level, quest log and equipped items, stamps the capture and stores it for the next reload.

    /anavdiag snapshot <anonymous-profile-id> AzerothNavigator: snapshot stored (<n> bytes). /reload or logout, then import AzerothNavigatorDB / snapshot_export from the selected SavedVariables file.
  2. II

    Bring it to the table

    After a reload or logout, import the SavedVariables file or paste the export text. Navzeroth can watch one file you select. Older, duplicate or malformed snapshots never replace the current one.

    WTF\Account\<account>\SavedVariables\AzerothNavigator.lua The conventional location. You select the file; nothing scans your account folders.
  3. III

    Chart the course

    Work the Atlas, Planner, Gear, Party and Dungeons screens against that snapshot and your active content. When the route is set, export it as plan text.

    Plan session › Export plan › Copy plan Each export carries its byte count, plan id and expiry.
  4. IV

    Ride with the lantern

    Back in game, open the paste window, import the plan and let the HUD keep your step in view. The plan lives only until the next reload.

    /anavplan paste Paste ANAV1 plan (32 KiB). Import explicitly; reload clears plan.
Make camp

Set up camp in five steps.

The preview installs for your Windows user only and needs no administrator rights.

The full Windows guide

  1. 01

    Gather the release

    From the 0.9.2 release page, download the setup file, SHA256SUMS.txt, SOURCE_COMMIT.txt and the notes.

  2. 02

    Check the seal

    Compare the installer's hash with its line in SHA256SUMS.txt. A match shows the download is intact. It does not prove who published it, so download only from the project's release page.

    Get-FileHash .\AzerothNavigator-0.9.2-x64-setup.exe -Algorithm SHA256
  3. 03

    Raise the tent

    Run the setup file. It installs into %LOCALAPPDATA%\Azeroth Navigator and uses Microsoft Edge WebView2. Until releases are code-signed, SmartScreen may warn you: choose More info › Run anyway only for a file whose checksum matches.

  4. 04

    Carry the addon in

    From the Start menu, open Azeroth Navigator - WoW addon, choose Install and select your game's Interface\AddOns folder. Nothing guesses where it lives. You can also extract the addon zip there by hand.

  5. 05

    Light the lantern

    Start the game, enable Azeroth Navigator Diagnostics in the AddOns list and record your client build before the first capture. The 0.9.2 adapters experimentally accept 1.60.1.70338 and 1.60.1.70374 with interface 16001, and 1.60.1.70425 for development capture only (UNVERIFIED).

The artificers' workshop

Rust at the forge, Lua in the field.

A Rust workspace holds the domain, ingest, storage, application and command-line crates. The desktop is a Tauri shell around a React interface, and the addon is plain Lua checked against the same fixtures by a Rust harness. Exchange formats are versioned JSON schemas, and synthetic fixtures are always labelled.

crates/core
Domain model: predicates, travel, eligibility and gear scoring
crates/ingest
Bounded ANAV1 and SavedVariables parsing
crates/storage
SQLite snapshot store, migrations, backup and recovery
crates/app
Application services behind the desktop commands
crates/cli
azeroth-cli for diagnostics, content, packs, replay and release checks
crates/lua-harness
Runs the addon's Lua against the shared predicate and plan fixtures
apps/desktop
Tauri 2 shell with a React 19 interface
addons/AzerothNavigator
Diagnostics, capture, plan import, HUD and session recording
