FIELD NOTES / 03AZEROTH NAVIGATOR

INSTALLATION

Pack carefully.
Keep your records.

The current public download is 0.9.2. Check its identity and limitations before installing the unsigned Windows development preview.

Download from the project release

Open the published 0.9.2 release ↗

Get the Windows x64 installer or addon ZIP together with SHA256SUMS.txt, SOURCE_COMMIT.txt and the release notes. Compare each payload hash with its exact manifest entry.

Get-FileHash .\AzerothNavigator-0.9.2-x64-setup.exe -Algorithm SHA256

A matching checksum establishes integrity. It does not establish a signed publisher identity. Read the signing status.

Windows desktop

  1. Check the release notes and verify the download checksum.
  2. Run the installer for your Windows account. The default folder is %LOCALAPPDATA%\Azeroth Navigator.
  3. If WebView2 is missing, its Microsoft bootstrapper needs network access during setup.
  4. Open the companion and import a snapshot explicitly. The application does not connect to a live game session.

In-game addon

  1. Close WoW and back up your existing addon and SavedVariables.
  2. Extract the ZIP's AzerothNavigator folder into the client's actual Interface\AddOns folder.
  3. Enable Azeroth Navigator Diagnostics in the AddOns list.
  4. Record the exact build, interface and installed source when testing. Admission is not full live acceptance.

Upgrade with a consistent backup

In the application, use Backup and recovery → Create consistent backup. Keep the backup outside installation and application-data folders, then close the companion before upgrading. Inspect your imported data and research selections after installing the newer version.

Older writers refuse newer private-index schemas. Do not overwrite a database or bypass a refusal to force an older executable to run.

Remove only what you intend

Uninstall the desktop through Windows Installed apps. Retained application data and backups are separate; delete them only if you intend to lose that state. With WoW closed, remove the owned addon folder. Removing SavedVariables is a separate decision.
